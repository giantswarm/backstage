A new-session link (`/?agent=<installation>/<namespace>/<name>#prompt=…`) selects its agent when the installation in it is none the portal knows, as when an agent writes the name agent-manager reports, by matching the one agent of that namespace and name. A linked agent that is not selected is said above the composer, by cause, instead of the default being selected silently. A prompt from a link puts the focus in the prompt field, with the caret after the text, once the linked agent is settled and unless the person is already doing something on the page.
