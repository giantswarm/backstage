`Breadcrumbs` (and so every `ShellPage` with breadcrumbs) leads with a back arrow: an icon link to the nearest ancestor that has an href, labelled "Back to <ancestor>" for assistive technology. A trail without a linked ancestor has no arrow. At phone width the arrow is a 44px target without making the row taller.
