Continue the chat automatically when muster's approval page or connector sign-in returns the browser: the tab muster returned to tells the chat tab that opened it (over a `BroadcastChannel`, or a `storage` event where there is none), which sends _Done_ itself once, only for the open it made, in that session and as that person. The return tab says "Done — you can close this tab" and closes itself when the browser allows it. _Done_ stays as the fallback.
