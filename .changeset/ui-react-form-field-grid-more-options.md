Two form building blocks for the create flows: `FormFieldGrid` puts fields side by side (two columns from bui's `sm` breakpoint) with their inputs on one line regardless of how long each label or description runs — each field's label, control and error sit on shared rows through CSS subgrid — and `MoreOptions` is the agent wizard's "More options" disclosure (a controlled native `<details>` with a one-line summary of what it holds), for a flow's technical knobs.
