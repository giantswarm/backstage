The agent wizard's Skills step lists plugins as Claude Code plugins and Agent Plugins packages in two groups, one row per plugin with its skills folded away and a search over plugins and their skills. An Agent Plugins package's checkbox picks every skill it has at the commit shown; a Claude Code plugin's row shows its skills without checkboxes. An edited agent that loads a package whole at an older pin shows it checked instead of unpicked.
