Agents: the facts beside an agent's overview name its Runtime in the create
form's words: the Harness's title, Platform default on the platform Harness,
and its name and image beneath, with an info hint saying what the runtime is.
A Harness you cannot read is shown by its name, and an agent that names none
reads Unknown runtime. The cards under Customize → Agents' "Last used by you"
open the agent's page, like every other item of the list, instead of starting
a session; the page's Use this agent starts one.
