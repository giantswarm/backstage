The Notifications submenu of a session's actions menu labels each level by when it notifies: **When action is required** (was Default: the session waits for you or fails), **When action is required or a turn finishes** (was All activity) and **Muted**. A session started outside the portal, which notifies only when it waits, is no longer offered the turn-finished choice.
