A session shows every URL elicitation an agent waits on the same way, whatever the page asks for: muster's sign-in, its approval page for a tool call that asks, or any later page. The server's message is the heading, _Open_ names the host the link leads to, and _Done_ / _Not now_ answer. A link on the origin of the session's muster returns to the session with the elicitation's `elicitationId`, and the tab that opened it lets the agent continue.
