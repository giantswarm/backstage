Inside the agent-platform shell, an agent's page, a model's page, Model hosting and Usage use the shell's standard page frame: breadcrumbs, one title at the standard scale, and the page's tabs and actions in its header, with no second heading under the shell's. An agent's page reads in plain language, with the tabs Overview, Sessions and Usage: the Overview says what the agent is for and shows its instructions, its skills as cards that open each skill's page, what it can reach, and its model and environment beside it, with the Kubernetes detail (configuration, status, HelmRelease, GitOps source, skill versions) behind "Show technical details", shown from the start while the agent is not ready. Edit and "Use this agent" sit in the header, Update skills in the Skills section, and delete and the manifest in the actions menu. The Usage tab shows the agent's estimated cost, tokens and model calls from the gateway, your sessions with it and any runtime-reported cost, with a link to the Usage screen. Model hosting gathers Serving and GPU capacity under one titled page. The Usage views no longer repeat their tab's name as a heading, in either frame. Classic chrome keeps its existing pages.
