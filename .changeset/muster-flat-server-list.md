MCP servers: the servers page is one flat table — **Server · Status · Tools · Auth · Source**, sorted by name and sortable by any column — instead of three tool-group sections of expandable rows. A server family is one row, marked with a **Family** pill and a status such as "24 of 26 instances healthy"; a singular server is one row; muster's own tools are one row marked **Core**. The name is a plain link to the server page; every other cell is plain text. Source says whether a server is a Fleet server, a User-registered server or muster itself; Tools counts the row's tools, or says "Sign-in needed" for a server whose tools wait on the person's sign-in. The search (`?q=`) keeps the servers whose name matches or that offer a matching tool (short name or description, the rule the Tools tab filters with); a row matched by its tools says "N of M match" and opens its Tools tab with the same filter. Without a muster session the table still lists the servers from the CRDs, searches names only and says what the session adds. The endpoint and the server/tool totals sit on one line above the table. The accordions, their per-cluster pills and action rows are removed, and so is the "updated … ago" indicator: the list re-reads every 30 s, as the Agent Platform's other tables do.
