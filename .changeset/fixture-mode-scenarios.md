Fixture mode serves scenarios, outside production builds only: `?fixtures=empty`, `many`, `long-names`, `loading` or `error` on any page switches the data set every fixture API reads without a restart, and `?fixtures=base` goes back. In `error`, muster fails with its own signed-out, unauthorised and unreachable errors.

The Toolchains tab says "Toolchains could not be checked" when no environment's Muster answers whether it runs the toolchain-manager, instead of reading forever.
