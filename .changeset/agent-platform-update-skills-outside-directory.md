Update all skills to latest no longer offers a pull request agent-manager cannot open. For an agent applied from Git, once the dialog shows skills that would move and no violations, it also runs agent-manager's commit dry run, which checks the repository, and says so while it runs; the table then shows the pins that dry run would commit. When agent-manager has no file for the agent's HelmRelease in its directory, the dialog names the release, the file agent-manager looked for and the repository, says to change the pins in the file that defines the release, and disables **Open pull request**. The same explanation replaces agent-manager's raw `conflict` message when the write itself is refused that way.
