Agent Platform: a **marge** tab (`/agent-platform/marge/<team>`) that lists a team's open bot PRs as marge classifies them and runs the sweep's own steps, through marge's MCP tools over muster as the signed-in person, with no agent in the path. The team selector defaults to the person's catalogue team, any team can be typed; the table shows kind, update type, age, classification, last evidence line and rescue state, grouped by repository or by dependency. The table is marge's stored classification (`x_marge_list`); **Refresh classification** is the one live read and only ever a click. **Preview sweep** shows what a sweep would do to each PR (`x_marge_sweep` with `dry_run`), **Apply** runs exactly that on the PRs the preview listed, ticked one by one under a `per-pr` policy. Per PR: **Merge** and **Refresh branch** (`x_marge_sweep` narrowed to the PR), **Remedy** (`x_marge_remedy`, the catalogue rule under its own guards; no direct rerun) and **Mark blocked** (`x_marge_mark`). A refusal is shown with the engine's reason and nothing offers a way around it. A person without a GitHub grant gets the muster plugin's per-server Sign in.
