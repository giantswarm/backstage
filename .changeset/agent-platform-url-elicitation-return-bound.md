The return from a URL elicitation's page resumes the agent only for the open the tab itself made: each _Open_ carries a new random value in the `redirect`, which the return must bring back with the elicitation, and only for the same task, session page and person, once. Only muster's approval page and its sign-in start get a return, not any page on muster's origin; the approval page's return names the elicitation muster recorded. A visit to a session page with a known `elicitationId` no longer answers _Done_.
