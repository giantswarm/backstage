A new model of an organization, from New model or from the organization's Add model, no longer changes a model of the same name that another person made in the meantime: where the installation's agent-manager supports it, the write is refused and the page says that a model with this name exists and to choose another name. The credential form says the same when the name is taken at its save. On an older agent-manager nothing changes.
