Add the workspace editor (`/agent-platform/workspaces/new` and `/agent-platform/workspaces/<installation>/<organization>/<name>/edit`): sources on any provider instance with repositories by name, language and topic filters, exclusions, archived and forks; a repository picker that pages an owner's repositories from the server; a live preview of what the draft selects; the manager's validation message on the field it names; and an inline connect prompt (`ProviderConnectPrompt`) for a provider the person has not connected.
