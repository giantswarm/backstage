A cluster's Gateways tab lists the cluster's Gateway API ReferenceGrants: each grant's namespace, the kinds and namespaces that may reference into it (From), and the resources they may reference there (To): one named resource, or any resource of a kind. A kind outside the core and Gateway API groups names its group. They load on their own, so they stay shown when the Gateway API topology fails to load, and at phone width they stack. On a Platform cluster's Gateways tab, the selected Gateway lists the ReferenceGrants that let its HTTP routes reach a backend in another namespace, or let Gateways in its namespace reference into the grant's, with the routes or Gateways each one is for; the others are listed under "Not attached to a gateway", and the finder finds a Gateway by the name of a grant on it. The data comes from the `gatewayapi_referencegrant_*` metrics, which observability-bundle exports since 3.3.0. gs-common adds the `GatewayApiReferencegrantCreated`, `GatewayApiReferencegrantFromInfo` and `GatewayApiReferencegrantToInfo` metrics, and fixture mode serves the ReferenceGrants of the fixture routes.
