Add `ShellPage`, the agent-platform shell's page frame (breadcrumbs, a title row with badges and actions, routed tabs, the content with an optional column beside it), `FullScreenWizardFrame`, a create flow over the whole viewport with a step strip, Close, Cancel and Back, `FactsColumn`, the facts column beside a detail page's content, and `StatusDot`, a state dot in the bui colour of its tone, or an app's custom property named by `colorVar`, with an optional label.

`FactList` takes an optional `stacked` prop that puts each label above its value. Without it the list renders as before.
